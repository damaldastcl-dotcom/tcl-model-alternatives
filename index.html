Pick the customer’s model below. You get the alternatives in the internal guide’s pick order: same size and same series first, same generation before next generation, and the same TV platform by default. Higher series at the same size are also offered as step-up options, labelled 1st, 2nd, and 3rd upgrade, so the size of any jump is clear before you offer it. If a spec needed for a comparison is blank in the source, the picker does not drop the model: it checks the same series in the library first, and if the exact spec is still not on file it uses a best guess and flags that suggestion as estimated, so you know to validate it. If the customer’s model is a 2024 Holiday model, the Holiday path applies: the guide replacement is generally an upgrade at the same size, shown first in the results.

Reference & guides

How the pick order works
  1. First: same size, same series, same generation. The closest match at the customer’s size, in the same series and the same model generation, on the same platform. Staying at the same size outranks every other change.
  2. Second: same size, same series, next generation. The same series at the same size, one generation newer. A 65QM8K becomes a 65QM8L before any platform change is considered.
  3. Third: same size, same series, different OS. The same series and size on a different platform comes last in the main order. The picker keeps the same platform by default. OS swap disclaimer: do not offer a platform change proactively. Offer only if the customer requested that platform, or if the Warranty Team approves it internally. Fire OS is not offered for an OS swap except as an approved exception.
  4. Step-up options are labelled by the jump. Higher series at the same size and on the same platform are offered as a choice, labelled 1st upgrade, 2nd upgrade, and 3rd upgrade, counting series levels above the customer’s model. Nothing past the 3rd upgrade is shown. One level at a time is the norm: a 2-level upgrade needs approval first, and a 3rd upgrade is shown so the jump is visible, not as a routine pick.
  5. One size step up is separate. A single size up in the same series is not part of the main ranking. It appears on its own below the main picks, clearly marked, and it needs the customer’s agreement, noted in the case.
  6. Never a step down on your own. If only a lower tier is available, the customer has to agree first and the agreement goes in the case notes. If nothing in the order works, escalate to the Warranty Team lead instead of substituting down.
  7. Excluded models drop out. Anything you add to the Exclude list in step 1 is removed before the order is shown, so the first pick on screen is always the first one you have not already ruled out.
  8. Blank specs: research first, then a flagged best guess. If a spec needed to compare two models and make the decision is blank in the source (most often the pack tier or the panel), the picker first checks the library for that model: the same series at another size. If the exact spec is found that way, it is used and marked as filled from the library. If it still cannot be found, the picker uses its best guess, set at the entry level of the model’s display class so a guess never overstates the TV, and the model can still be suggested, and that suggestion carries an “Estimated spec — validate” flag naming the guessed value. An estimated value was made up to keep the comparison moving: validate it against the model’s spec sheet or a retailer listing before you offer the TV, and never quote it to the customer as verified. When the customer’s own tier is one of these guesses, step-ups are not ranked off the guess alone: each candidate is also checked against the customer’s stated specs (backlight class and panel), a candidate below the stated specs is left out as a step down and named as one, and the step-ups that remain are flagged as estimated and needing validation, never shown as confirmed upgrades.
  9. Holiday models follow the Holiday path. A model that matches a row in the 2024 Holiday Model Guide is a one-time model and generally unavailable, so its replacement is generally an upgrade at the same size: the guide alternative first, flagged Holiday / upgrade, then, if that alternative is not available, the next generation of the alternative, flagged as a further jump needing approval where it moves beyond the normal ladder. Series-only guide rows resolve to a same-size model in that series, and blank guide rows fall back to a general upgrade, not no option. The full mapping is in the Holiday panel in Reference & guides below.

Picker notes: where the internal guidance does not line up

Plain summary only. Where items conflict, this picker follows the ranking in “How the pick order works” and flags the conflict here rather than picking a side silently. Check the replacement options guide and the Alternate Model Tool before acting on a flagged item.

  • Size step up: a one size step up shows up in the guide’s worked scripts, but it is not in the guide’s main list of replacement options. That is why this picker keeps it as a separate, clearly marked option instead of a main pick.
  • Platform order: this picker keeps the customer on the same platform by default, yet the guide’s option order still places a different OS third. Those two ideas pull in different directions, so different OS picks are shown in the main order but marked, and they need the customer’s agreement.
  • A-stock age limits: the age thresholds for A-stock differ between the main guide and other internal articles. Do not rely on a single age cutoff without checking which article applies to the case.
  • 32 inch recertified sets: the current rule for 32 inch recertified replacements differs from what a 2022 article states. Treat the older article as out of date on this point until the guidance is reconciled.
  • Canada: Canada follows a separate recertified only rule, with exceptions. Do not apply the US pick order to a Canadian case without checking the Canadian rule and whether an exception covers it.
  • Bulk OneDrive packs added: 743 pack rows were added to the picker library, Google TV first (327 rows), then Fire TV and Roku TV (416 rows, including 21 Android TV rows labelled as Android TV). 617 of these models are new to the picker and are marked Bulk pack in the list. The other 126 were already in the picker from TCL USA, so nothing about them changed except that their pack source and conflict flag now show on the model.
  • Bulk pack conflicts: 239 of the 743 pack rows carry a conflict flag. A conflict flag means the bulk pack data for that model differed from the existing library value in at least one field: the existing value was kept, and the differing pack value is noted on the model rather than applied. The flag and the pack source are shown on the model itself so the conflict is visible before the model is offered.
  • Blank-spec estimates: 606 of the 743 pack rows state no tier and 317 state no panel, and tier is the column the step-up ranking decides on. Where a blank value is needed for a comparison, the picker fills it from the same series in the library first. Where that series states no value anywhere, it shows a best guess set at the entry level of the model’s display class, marked Estimated on the model and flagged on any suggestion that used it. Treat every Estimated value as unvalidated until it is checked against a spec sheet.
  • Step-up ranking guard: when the customer’s tier is estimated, step-ups are cross-checked against the customer’s stated backlight class and panel before they are shown. A candidate below the stated class is excluded as a step down and named on the model. Example: the 55R646 states Mini LED in its specs but no tier, and its guessed tier 6 once ranked the 55Q651G, a stated QLED, as its 3rd upgrade. The Q651G is now left out as a step down, and the step-ups that remain for the R646 are flagged as estimated, not confirmed upgrades.
  • Bulk pack exclusions: models with no verified OS were not added (71 distinct models), and neither were the 2013 PDF models with no smart OS stated. Neither group appears in the packs or in this picker.
2024 Holiday Model Guide: the Holiday path

A model is a Holiday model when it matches a row in the 2024 Holiday Model Guide exactly. Holiday models are one-time and generally unavailable, so the replacement is generally an upgrade, and the size stays the same in every row. When a Holiday model is picked above, this path shows first in the results, flagged Holiday / upgrade, ahead of the normal pick order. Canada rows are the models with the -CA suffix: type the full model number, suffix included, in the search box.

  • Guide alternative first. Send the alternative the guide names, flagged Holiday / upgrade.
  • Guide alternative not available: check the next generation of that alt model. Add the unavailable alternative to the Exclude list in step 1 and the picker checks the next generation of it. That step is a further jump past the named alternative, so it is flagged, and it needs approval before it is offered where it moves beyond the normal ladder.
  • Series-only rows name a series, not a model. The picker resolves them to a same-size model in that series from the library, as shown in the tables, and treats it as an upgrade. Where no model in that series at that size is in the library, the row says so and the fallback is a general upgrade.
  • Blank rows name no comparable model. That is not no option: fall back to a general upgrade at the same size, using the step-up options, labelled by jump.
  • S4BH is a soundbar, not a TV. Its guide alternative is the S45H. The TV size ladder does not apply to it, and it is not in the TV model list.

About the model data

The pick order on this page follows the internal replacement guide ranking: same size, same series, same generation first, then same size, same series, next generation, then same size, same series, different OS, with the same platform kept by default and a one size step up kept as a separate option. See the How to Determine Replacement Options guide and the Alternate Model Tool for the full internal guidance. The model list, sizes, and specifications come from TCL USA, checked October 30, 2026: the full tcl.com US store catalog (every TV series, size, and SKU) and the series pages behind it. DisplaySpecifications, retailer MSRP listings, and release-date searches were used as cross-checks only. Where a cross-check disagrees with TCL USA, the page follows TCL USA and the model carries a source check note saying so. List prices are TCL USA list prices or published launch MSRP, never current sale prices, and they only support the ranking. TCL’s designer frame TVs (A300 series) and the FHD Q3 lines are not in the ladder because they are different product types, not step-up or step-down matches for the 4K lines. The picker library also includes the Bulk OneDrive data packs, added October 30, 2026 in this order: the Google TV pack (327 rows) first, then the Fire TV and Roku TV pack (416 rows, including 21 Android TV rows labelled by OS). Pack models carry their size, OS, series, tier, panel, and key specs as stated in the pack, with the pack source and conflict flag shown on the model. Pack data did not overwrite any TCL USA specification already in this picker: where a pack row conflicts with TCL USA, the TCL USA specification stands and the conflict is flagged in the picker notes and on the model. 71 distinct models with no verified OS and the 2013 PDF models with no smart OS stated were not added.
